# python-fastapi-beyondcrud

## windows

### Install python

#### Add python and python/scripts into the system path
#### Check python version: py --version
#### Goto project folder and create python virtual environment - py -m venv env
#### Once env folder is created, run the script - env/Scripts/activate

### Install fastapi

#### Run - pip install fastapi
#### If the above command fails in windows powershell / terminal, Run this command - pip install --only-binary :all: fastapi[all]
#### To confirm installation - Run - py -> import fastapi
